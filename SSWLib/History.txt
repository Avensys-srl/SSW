SSW Changelog
=============

2.0.0.16 - 2026-09-21
---------------------
- Made upright SSC floor schematics depend on the catalog `SSC_UPRIGHT` reference view instead of the historical A1/B1 code list.
- Applied the same catalog-driven geometry to the interactive installation page and generated reports.

2.0.0.15 - 2026-09-21
---------------------
- Removed the startup updater deadlock caused by awaiting the installer download while the WinForms UI thread was synchronously waiting for the update check.
- Routed automatic update packages through the direct static distribution path while keeping invitation downloads protected by registration tokens.

2.0.0.14 - 2026-09-21
---------------------
- Added model-specific STEP archives to the Documents page when the corresponding file is available, with verified download and local caching.
- Moved the project document language selector into the initial Project page alongside the interface language selector.

2.0.0.12 - 2026-09-21
---------------------
- Simplified approved customer activation to require only the registered email address and six-digit PIN; profile data is reused from the portal registration.

2.0.0.11 - 2026-09-21
---------------------
- Return automatically to PIN activation when a previously registered local license has been deleted or rejected by the server.
- Allow an archived installation belonging to a deleted user to be safely reassigned after a new approved registration.
- Accept harmless differences in the company name during activation; identity remains bound to the approved email and PIN.

2.0.0.6 - 2026-09-17
--------------------
- Aligned setup and activation language with the Windows display language and enabled all available installer translations for supported SSW languages.

2.0.0.5 - 2026-09-17
--------------------
- Split activation into explicit request, waiting and PIN-entry phases; the PIN field remains hidden until the user confirms that the code was received at the registered email address.

2.0.0.4 - 2026-09-17
--------------------
- Clarified that the code entered after submitting a license request is the six-digit activation PIN, not the four-character device identifier.

2.0.0.3 - 2026-09-17
--------------------
- Added a two-step activation flow: the user accepts the terms and sends a visible license request before the PIN field is shown.
- Persisted pending requests locally, exposed them in the license portal and added a notification badge for new license activity.
- Moved the update check before license enforcement so future blocked installations can still receive software updates.

2.0.0.2 - 2026-09-16
--------------------
- Added a fourth preselection criterion that restricts results to rotary heat recovery units in families 6 and 9, with full localization and project persistence.
- Restored the automatic software-update check when the guided UI opens and added a release-gate probe for older installed versions.

2.0.0.1 - 2026-09-16
--------------------
- Corrected horizontal floor-mounted East-West configurations with front access to use the upright mounting schematic in both the guided UI and technical report.

2.0.0.0 - 2026-09-16
--------------------
- Made the guided WebView2 technical-selection interface the default SSW experience.
- Preserved the existing calculation engine, offline product database and historical project compatibility behind the new workflow.
- Added automatic signed SDF catalog updates with compatibility checks and local fallback.
- Added email and six-digit PIN device activation, two-device licensing, offline renewal, revocation and localized privacy acceptance.
- Added project selection management with distinct room/location references, explicit accessories and duplicate-unit support.
- Reworked installation and airflow schematics in both the UI and RDLC reports, including SSC, OSC, FS/VS/HCI and ST layouts.
- Added localized dimensional drawings, improved summaries and reports, and completed supported-language coverage for the new UI.
- Updated the public installer to use PIN activation without embedding the obsolete bootstrap credential.

1.3.0.55 - 2026-07-22
---------------------
- Added private per-installation follow-up reminders for emailed selections and multi-selection projects.
- Added configurable 1-90 day scheduling, a localized notification centre, due badge, reopen, reschedule, success, unsuccessful and cancel actions.
- Added offline-first atomic reminder storage, ordered idempotent synchronization and authenticated paginated API refresh.
- Added localized follow-up guidance and bell help in all 14 supported languages, with the pre-release Help/UX audit added to the release gate.
- Added Norwegian and Icelandic accessory-catalog translations to the central database and regenerated the AV product database.

1.3.0.54 - 2026-07-22
---------------------
- Added Norwegian and Icelandic as fully supported application languages while keeping language names readable in their native form.
- Added a localized in-application user guide covering selection, calculation, saving, alternatives, reports, projects and email workflows.
- Added optional contextual help tips for controls and File-menu commands, enabled by default on new installations and retaining the existing preference after updates.
- Updated the AV product database with the latest electric-heater relationships for SG and PRIME units.
- Added approved technical roadmaps for installation layouts and local follow-up reminders.

1.3.0.53 - 2026-07-21
---------------------
- Added multi-selection projects with localized project names, reusable selection links and consolidated PDF email composition.
- Added centralized best-effort synchronization of projects and their selection summaries while preserving offline operation.
- Corrected technical-selection idempotency so an updated customer reference can be registered without reusing a stale request key.
- Added update-download context so the server can distinguish first downloads from application updates.
- Added localized project management and email content in all supported languages.
- Removed the obsolete bootstrap credential requirement from public AV installer builds.

1.3.0.52 - 2026-07-20
---------------------
- Modernized application and report performance charts with high-resolution PNG rendering and circular working points.
- Synchronized airflow axes and intervals across pressure, absorbed-power and efficiency charts.
- Split winter and summer efficiency into aligned seasonal plots with a shared 60-100 percent scale.
- Corrected unstable initial summer-efficiency samples and standardized seasonal curve styling.
- Extended pressure curves ending above 10 Pa to their interpolated zero-pressure airflow.
- Refined report chart margins, frames, legends and axis-title alignment to prevent clipping.

1.3.0.51 - 2026-07-15
---------------------
- Added progressive alternatives that duplicate a selection and prefix its customer reference with Alt. 01, Alt. 02 and subsequent numbers.
- Added a localized acknowledgement disclaimer for customized water-coil designs and persisted its acceptance in selection projects.
- Exposed the localized custom-coil disclaimer acceptance in all water-coil report datasets.
- Clarified that displayed dimensions refer only to the water coil and that overall dimensions, delivery time and quotation must be requested.
- Refined the localized water-coil report layouts.
- Kept only the latest verified installer and manifest in the public distribution folder while retaining local build history.

1.3.0.50 - 2026-07-15
---------------------
- Made first-run registration automatic for public AV installations even when the installer bootstrap credential is unavailable.
- Used the AV distribution profile rather than the product-database management code as the API customer identity.
- Retained installation-specific access tokens, revocation and server-side registration rate limiting.

1.3.0.49 - 2026-07-15
---------------------
- Completed in-app updates without requiring a Windows restart.
- Closed the running SSW instance before replacing application files and reopened the updated release through the installer.

1.3.0.48 - 2026-07-15
---------------------
- Fixed zero-touch technical-selection enrollment on newly installed PCs.
- Provisioned the one-time customer bootstrap credential in the application registry and consumed it after successful registration.
- Retained environment-based bootstrap lookup for compatibility with existing installations.

1.3.0.47 - 2026-07-15
---------------------
- Added a sanitized customer-reference prefix (maximum 30 characters) to suggested selection filenames.
- Constrained the heating/cooling water temperature fields to a valid direction and a minimum water delta T of 1 K.
- Added localized warnings for low water delta T (3 K inclusive to 5 K exclusive) and water-side pressure drop above 40 kPa.
- Clarified that calculated coil outlet air temperature is the maximum value at fully open valve.

1.3.0.46 - 2026-07-15
---------------------
- Centralized the release version so SSW.exe, SSWLib.dll, ClickOnce, installer and manifests cannot drift independently.
- Removed the obsolete Accessory tab and the legacy structured COILcalc integration.
- Retained the HEDes local water-coil calculation used by the Water Coils tab.
- Added local approximate country/city geolocation without storing selection IP addresses.
- Added the authenticated Avensys recovery panel with immutable revision export and audit.
- Added verified update manifests with component versions, SHA-256, compatibility and rollback metadata.
- Added installer download integrity enforcement and localized integrity errors in all 12 languages.
- Updated the distributed AV database to schema 2 with electric-heater data and model relations.
- Added historical SDF/project fixtures, an automated release matrix, health checks and release runbook.
- Defined technical-selection privacy and retention controls for audit and download logs.

1.3.0.45 - 2026-07-14
---------------------
- Added versioned SDF compatibility checks and database metadata diagnostics.
- Added reusable .sswsel project files with new, open, save, duplicate and recent-selection workflows.
- Added immutable technical selection snapshots, centralized opaque references and revision tracking.
- Added local progressive draft references and offline report fallback.
- Added translated technical selection reference, revision and status fields to all report layouts.
- Added zero-touch installation enrollment with DPAPI-protected access tokens and revocable bootstrap credentials.
- Fixed bootstrap credential lookup for already-running Windows sessions.
- Kept automatic update checks silent when the update service is unavailable.

1.3.0.44 - 2026-07-13
---------------------

- Integrated water coil selection and real performance calculations through COILcalc.
- Added heating, cooling and combined HCD calculation modes using the correct seasonal supply conditions.
- Added internal and external coil installation options, with model-specific defaults and geometry customization.
- Applied coil air pressure drops to the unit performance curve and limited airflow to the admissible operating point.
- Added water-side pressure drop, fluid flow rate and medium velocity results.
- Extended reports with seasonal exchanger and water coil performance sections.
- Added Swedish localization and completed water coil translations for all supported languages.
