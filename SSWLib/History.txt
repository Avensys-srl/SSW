SSW Changelog
=============

1.3.0.41 - 2026-06-17
---------------------
- Fixed blank pages in generated reports when the sound table includes the EN ISO 16032 row.
- Split the main report layout so the CO2 section is only loaded when explicitly included.
- Hid the SAP report container when SAP data is not shown, preventing empty page breaks.

1.3.0.40 - 2026-06-17
---------------------
- Added visible progress feedback while downloading update installers.
- Fixed the update installer download flow so the application no longer appears frozen during long downloads.
- Fixed the build warning caused by uninitialized QUARK breakout sound values.
- Updated installer architecture settings to avoid deprecated Inno Setup identifiers.

1.3.0.39 - 2026-06-16
---------------------
- Added Inno Setup installer generation with automatic signing.
- Added automatic installer copy to the release distribution folder.
- Added update API support for installer packages while keeping legacy package compatibility.
- Improved the application update flow to download and start the installer after user confirmation.

1.3.0.38 - 2026-06-16
---------------------
- Added a Changelog button to the About window.
- Changelog is loaded from the local History.txt file, so it works with the private repository.
- Confirmed the motor sound power correction coefficient.
