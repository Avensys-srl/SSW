SSW Changelog
=============

1.3.0.44 - 2026-07-13
---------------------
- Added seasonal winter and summer thermodynamic calculations and efficiency curves.
- Integrated water coil selection and real performance calculations through COILcalc.
- Added heating, cooling and combined HCD calculation modes using the correct seasonal supply conditions.
- Added internal and external coil installation options, with model-specific defaults and geometry customization.
- Applied coil air pressure drops to the unit performance curve and limited airflow to the admissible operating point.
- Added water-side pressure drop, fluid flow rate and medium velocity results.
- Extended reports with seasonal exchanger and water coil performance sections.
- Added Swedish localization and completed water coil translations for all supported languages.
- Improved high-resolution report charts and fixed localized numeric parsing in coil calculations.

1.3.0.43 - 2026-07-06
---------------------
- Added enthalpic exchanger calculation support for EN366 and ENRFC27.
- Separated thermal efficiency from humidity efficiency for enthalpic exchangers.
- Added dedicated humidity efficiency curves from Recutech selector data.
- Forced produced water to zero for enthalpic exchangers.

1.3.0.42 - 2026-06-17
---------------------
- Updated the AV machine database.
- Added SG series 6 models 356 and 456.

1.3.0.41 - 2026-06-17
---------------------
- Fixed blank pages in generated reports when the sound table includes the EN ISO 16032 row.
- Split the main report layout so the CO2 section is only loaded when explicitly included.
- Hid the SAP report container when SAP data is not shown, preventing empty page breaks.

1.3.0.40 - 2026-06-17
---------------------
- Added visible progress feedback while downloading update installers.
- Fixed the update installer download flow so the application no longer appears frozen during long downloads.
- Fixed the build warning caused by uninitialized QUARK breakout sound values.
- Updated installer architecture settings to avoid deprecated Inno Setup identifiers.

1.3.0.39 - 2026-06-16
---------------------
- Added Inno Setup installer generation with automatic signing.
- Added automatic installer copy to the release distribution folder.
- Added update API support for installer packages while keeping legacy package compatibility.
- Improved the application update flow to download and start the installer after user confirmation.

1.3.0.38 - 2026-06-16
---------------------
- Added a Changelog button to the About window.
- Changelog is loaded from the local History.txt file, so it works with the private repository.
- Confirmed the motor sound power correction coefficient.
