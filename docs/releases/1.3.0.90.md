# SSW 1.3.0.90

- Automatically checks the published DataCentral catalog before opening SQL Server Compact.
- Shows catalog check and update progress during normal startup.
- Validates manifest compatibility, customer, schema, size, SHA-256 and the downloaded SDF.
- Replaces the live catalog only after validation and retains `DataCentral.sdf.previous`.
- Falls back to the previous catalog on network or validation failures and writes `catalog-update.log`.
- Records the applied catalog version separately because SQL Server Compact modifies the file after opening.
- Automated smoke and screenshot commands do not contact the catalog endpoint.

## Verification

- AV/x86 desktop and frontend builds pass.
- Live schema 6 catalog publication, manifest download, byte length and SHA-256 verified.
- First-start update and second-start no-redownload behavior verified.
